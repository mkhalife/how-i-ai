How I AI

People describe how they use AI. This shows it, from your own session history: Claude, Claude Code, Cowork, Codex, ChatGPT. Everything runs on your machine. Sharing with the team is optional and you see the exact rows first.

Run it

Each button opens the app with the prompt already typed. Read it, press Enter. The Claude chats and Claude Code on the web cards carry their whole prompt; the others tell Claude to fetch the instructions from this repository.

AI wrapped

The quick version: one prompt, nothing to install, no sharing step. Claude pulls your last 30 days of sessions from whatever it can see where it runs, classifies them, and builds the wrapped slide deck. Opens Claude Code on this computer, or a new claude.ai/code session for your cloud sessions.

Claude chats

The run opens this for you; use the button only if it did not. Your claude.ai chats are not on your disk, so Claude in a chat lists your last 30 days of them into one file to download, claude-chat-threads.json. Save it to how-i-ai/inbox in your home folder.

Claude Code on the web

The run opens this for you; use the button only if it did not. Cloud sessions are not on your disk either, so Claude in a new claude.ai/code session lists them into cloud-sessions.json to download. Save it to how-i-ai/inbox in your home folder.

Claude Code

The Claude run. Reads your Claude Code sessions and the Cowork sessions stored on this computer, opens the two surfaces above for your chats and cloud sessions and collects their files, and reads a claude.ai export if you have one. Opens a terminal with the prompt filled in; without a terminal, paste the prompt into the Code tab of Claude Desktop. Cowork itself cannot run it: it works in a separate VM that cannot see this history.

Chat only, from an export

Fallback only, for people without Claude Code. Chat cannot read your disk or run the scripts, so you request your claude.ai data export, upload the zip, and Claude builds the profile in the chat. Opens Claude Desktop.

ChatGPT desktop app

Covers your ChatGPT conversations, which only the app itself can list, and your Codex sessions. It is run separately from the Claude one; if you use both, run both. The button opens a new task in the app with the prompt filled in.

Open in the ChatGPT app

ChatGPT on the web

Fallback for people without the ChatGPT desktop app. chatgpt.com cannot list your conversations itself, so this path works from your ChatGPT data export: you request it, upload the zip, and ChatGPT builds the profile in the chat. Opens chatgpt.com with the prompt, which ChatGPT sends immediately.

Or install the skill

claude plugin marketplace add mkhalife/how-i-ai
claude plugin install how-i-ai@how-i-ai

Then ask Claude Code: "show me how I use AI", or run /how-i-ai:how-i-ai.

What you get

A wrapped-style profile page, rendered from your last 30 days: sessions per week, which tools, what for, whether AI informs you or does the work (ask, make, do), your biggest use case, the surprising one, and your most-used skills and custom agents.

WrappedThe design you get: story cards with a share card at the end EditorialAlternate template: annual-report typography, prints well TerminalAlternate template: dark monospace dashboard

Examples use generated sample data for a fictional product designer.

What the team sees

If you choose to share, your anonymized rows join the team sheet and the report answers: what is the biggest use case across functions, what is the surprise use case, how many sessions per week people have and how that is distributed, and how designers, PMs, and engineers differ on ask/make/do.

BoardroomDashboard for a leadership readout ExhibitPoster for the team meeting

What leaves your machine, and only if you say yes

Shareda random participant id, your function and title (title optional), and per session: source, date, week, weekday, hour, mode, category, subcategory, ask/make/do, a generic one-line paraphrase, surprise flag, message counts, duration, tool, connector, skill and agent names, model
Never sharedyour prompts or messages, session titles, file paths, repo or project names, machine name, email

You see the full table before anything is sent. Re-sharing replaces your earlier rows. To withdraw, send your participant id to the sheet owner.
