How I AI

People describe how they use AI. This shows it, from your own session history: Claude, Claude Code, Cowork, Codex, ChatGPT. Everything runs on your machine. Sharing with the team is optional and you see the exact rows first.

Run it

Each button opens the app with the prompt already typed. Read it, press Enter. The prompt only tells Claude to fetch the instructions from this repository.

Claude Code

Best option. Reads everything on this machine: Claude Code, Claude Desktop, Codex, and any export zips. Opens a terminal with the prompt filled in.

Open in Claude Code

Cowork

For people who do not use a terminal. Opens a Cowork session in Claude Desktop with the prompt filled in. Grant it your home folder when it asks.

Open in Cowork

Claude chat

Chat cannot read your disk, so this path works from your claude.ai or ChatGPT export zip that you upload. Opens Claude Desktop.

Open in Claude

ChatGPT

Same export-based path. Opens chatgpt.com with the prompt, which ChatGPT sends immediately.

Open in ChatGPT

If a button does nothing, the app has not registered its link handler yet: open the app once (for Claude Code, start claude and send any message), then try again. Or copy the prompt and paste it.

Or install the skill

claude plugin marketplace add mkhalife/howiai
claude plugin install howiai@howiai

Then ask Claude Code: "show me how I use AI", or run /howiai:howiai.

What you get

A profile page in one of three designs, rendered from your last 30 days: sessions per week, which tools, what for, whether AI informs you or does the work (ask, make, do), your biggest use case, and the surprising one.

WrappedStory cards with a share card at the end EditorialAnnual-report typography, prints well TerminalDark monospace dashboard

Examples use generated sample data for a fictional product designer.

What the team sees

If you choose to share, your anonymized rows join the team sheet and the report answers: what is the biggest use case across functions, what is the surprise use case, how many sessions per week people have and how that is distributed, and how designers, PMs, and engineers differ on ask/make/do.

BoardroomDashboard for a leadership readout ExhibitPoster for the team meeting

What leaves your machine, and only if you say yes

Shareda random participant id, your function and title (title optional), and per session: source, date, week, weekday, hour, mode, category, subcategory, ask/make/do, a generic one-line paraphrase, surprise flag, message counts, duration, tool and connector names, model
Never sharedyour prompts or messages, session titles, file paths, repo or project names, machine name, email

You see the full table before anything is sent. Re-sharing replaces your earlier rows. To withdraw, send your participant id to the sheet owner.
